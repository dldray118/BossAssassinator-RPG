# ser316-designPatterns-BossAssissinator

# Overview
This is a street fighter RPG game where the player fights through city streets to ultimately face and defeat the final boss. The game incorporates various design patterns from the Gang of Four to demonstrate their application in a game development context.

Summary of Design Patterns:
Decorator pattern will be used to wrap characters who gain experience and skill when defeating enemies.
Factory pattern will be used to create enemies of various skill depending on the current level.
State pattern will be used to transition from combat, exploring, and game over states.
